# Отчёты по веб-программированию

Общий сайт MkDocs для всех моих лабораторных работ. Основная конфигурация — `mkdocs.yml` в этой папке.

## Где редактировать отчёты

- [ЛР1](docs/lab1/index.md) — перенесён существующий отчёт вместе с пятью скриншотами; текст сохранён.
- [ЛР2](docs/lab2/index.md) — отчёт по текущему Go-проекту и подсказки для скриншотов.
- [ЛР3](docs/lab3.md) и [ЛР4](docs/lab4.md) — страницы для следующих работ.

Скриншоты второй работы класть в `docs/lab2/images/`. Рядом с каждой подсказкой в отчёте оставлена готовая Markdown-строка в HTML-комментарии. После добавления картинки нужно убрать `<!--` и `-->`, а саму подсказку удалить.

В папке первой работы старый `mkdocs.yml` теперь ссылается на общую конфигурацию. Даже сборка через старый путь включает все лабораторные. Копия первого отчёта в `laboratory_work_1/README.md` оставлена как была; источником страницы сайта служит `docs/lab1/index.md`.

## Локальная сборка

Из корня репозитория:

```powershell
cd students/K3339/laboratory_works/Hashimov_Ilham
python -m pip install -r requirements-docs.txt
python -m mkdocs build --strict
python -m mkdocs serve
```

Для просмотра открыть адрес, который напечатает `mkdocs serve`. Из-за `site_url` в адресе может быть путь репозитория. Команда `build` складывает HTML в `site/`; эта папка исключена из Git.

## Публикация позже

После заполнения отчёта и добавления скриншотов выполнить из этой же папки:

```powershell
python -m mkdocs build --strict
python -m mkdocs gh-deploy
```

`gh-deploy` создаёт коммит с HTML в ветке `gh-pages` и отправляет её в `origin`. Эту команду запускать при готовности к публикации. Она публикует весь сайт из общего `mkdocs.yml`, включая ЛР1 и ЛР2.

В настройках репозитория GitHub: **Settings → Pages → Deploy from a branch → gh-pages → /(root)**. Если этот источник уже выбран, менять его не нужно.

Ожидаемый адрес сайта: <https://ilhamVode.github.io/ITMO_ICT_WebDevelopment_2026-2027/>.

При добавлении следующей работы заполнить её Markdown-файл. Для новой страницы добавить пункт в `nav` общего `mkdocs.yml` и ссылку на главную страницу отчётов.

Описание параметров: [конфигурация MkDocs](https://www.mkdocs.org/user-guide/configuration/), [публикация на GitHub Pages](https://www.mkdocs.org/user-guide/deploying-your-docs/).
